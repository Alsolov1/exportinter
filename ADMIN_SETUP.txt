EXPORT INTER — Admin Dashboard setup

1. Supabase is already configured in admin.html with the Project URL and public Publishable Key.
   Never replace this with a service_role / secret key.

2. Upload the complete project contents to the same GitHub repository as index.html.
   The dashboard will be available at https://YOUR-DOMAIN/admin.html

3. Sign in using the administrator account created in Supabase Authentication > Users.
   Ensure public.profiles.role for that same user's UUID is 'admin'.

4. The dashboard uses:
   - public.equipment
   - public.categories
   - public.customer_requests
   - public.site_settings
   - storage bucket equipment-images

Important:
- The current public website still needs a separate integration change to read equipment and categories from Supabase and submit enquiries to customer_requests. This admin panel manages the Supabase records but does not yet migrate the existing Google Sheets catalogue automatically.
- Existing Google Sheets data is not deleted or imported by this package.


CATEGORY DISPLAY UPDATE
The public catalogue loads active categories from public.categories in Supabase. New active categories appear in the category filters after a page refresh. Assign equipment to a category in the admin dashboard to filter it under that category.
