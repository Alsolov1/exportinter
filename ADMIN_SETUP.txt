EXPORT INTER — Admin Dashboard setup

1. Open admin.html and replace:
   SUPABASE_URL = "PASTE_SUPABASE_PROJECT_URL"
   SUPABASE_ANON_KEY = "PASTE_SUPABASE_ANON_KEY"

2. Find both values in Supabase:
   Project Settings > API (or API Keys)
   - Project URL
   - anon / publishable public key
   Never use the service_role / secret key in browser code.

3. Upload admin.html to the same GitHub repository as index.html.
   It will be available at https://YOUR-DOMAIN/admin.html

4. Sign in using the administrator account created in Supabase Authentication > Users.
   Ensure public.profiles.role for that same user's UUID is 'admin'.

5. The dashboard uses:
   - public.equipment
   - public.categories
   - public.customer_requests
   - public.site_settings
   - storage bucket equipment-images

Important:
- The current public website still needs a separate integration change to read equipment and categories from Supabase and submit enquiries to customer_requests. This admin panel manages the Supabase records but does not yet migrate the existing Google Sheets catalogue automatically.
- Existing Google Sheets data is not deleted or imported by this package.
